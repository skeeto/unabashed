# M2: sequential interpreter

The working plan for M2, refining notes/plan.md. M2 makes the shell run
real scripts with one task at a time: no fibers, no concurrency.
Pipelines run stage by stage through buffers (an interim that M3a
replaces).

## Staging

1. **Core skeleton**, written serially because everything depends on
   it: the platform API additions below, `vos.cpp`, the variable store,
   word expansion, the executor, redirections and the builtin table.
2. **Modules in parallel**, each in its own new file with a narrow
   interface, so they merge without conflicts:
   - `arith.cpp`: arithmetic expressions;
   - `pattern.cpp`: glob and extglob matching;
   - `brace.cpp`: brace expansion;
   - `b_test.cpp`: test, `[`, and `[[ ]]` evaluation;
   - `b_printf.cpp`: printf without floats;
   - `fakes.cpp`: the vos programs, which also build as a Linux
     multi-call binary for the oracle container.
3. **Integration and spec hunting:** spec scripts per area, recorded
   from bash 5.3, then the fixes they lead to.

## Platform API additions

Errors are Linux errno numbers (`E_NOENT` = 2, ...). The core owns the
glibc strerror text. All paths given to the platform are absolute.

| Prototype | Notes |
|---|---|
| `Opened os_open(Os *, Arena, Str path, i32 flags)` | `{Handle h; i32 err;}`; flags `OF_READ OF_WRITE OF_CREATE OF_TRUNC OF_APPEND OF_EXCL` |
| `void os_close(Os *, Handle)` | |
| `iz os_read(Os *, Handle, u8 *, iz)` | existing |
| `b32 os_write(Os *, Handle, u8 *, iz)` | existing |
| `i64 os_seek(Os *, Handle, i64, i32 whence)` | -1 on error |
| `Stat os_stat(Os *, Arena, Str path, b32 follow)` | `{i32 err; i32 type; i32 mode; i64 size; i64 mtime; i64 dev; i64 ino; i64 uid; i64 gid; i32 nlink;}` |
| `Stat os_fstat(Os *, Handle)` | |
| `Dirent *os_list(Os *, Arena *, Str dir, i32 *err)` | linked list `{next, name, type}`, raw order |
| `Spawned os_spawn(Os *, Arena, Spawn *)` | runs to completion in M2 and returns the wait status: `{i32 err; i32 status;}` |
| `Handle os_dup(Os *, Handle)` | M2 needs it only for the vos |
| `i64 os_now(Os *)` | realtime, ns |

`Spawn` holds `path`, `argv`/`argc`, `env`/`nenv` ("NAME=value"),
`cwd`, and `fds[3+]`: the child's descriptor number mapped to a parent
`Handle`.

## Core representations

**Variables** (`vars.cpp`):
- `Var` is a hash-trie node keyed by name. It holds a stack of `Value`
  bindings: `local` pushes, function return pops (shallow binding).
- `Value` holds `{below, depth, attrs, str, num, ...}` and is immutable
  once published. An assignment allocates a new Value, or reuses one
  owned by the current scope.
- Special variables are dynamic, computed when read: `? $ ! # @ * - 0`,
  LINENO, RANDOM, SECONDS, BASHPID, and FUNCNAME from the call frames.

**Journal** (synchronous subshells: `( )`, `$( )`):
- The subshell copies `Shell` by value and records the store arena's
  watermark. Every write to a pointer slot below the watermark appends
  `{slot, old}` to the journal.
- On exit the journal is replayed backwards, the store resets to the
  watermark and the free lists are restored. The store's free lists
  hold only memory above the current subshell's watermark.

**Expansion** (`expand.cpp`) works on the parser's word text, as bash
does. It produces fields, each a byte string with a parallel flag
string:
- `XF_QUOTED`: the byte is not special to globbing or splitting;
- `XF_SPLIT`: the byte came from an unquoted expansion and IFS may split
  it.

`"$@"` and `"${a[@]}"` emit field breaks directly. Words with no `$`,
backquote, quote, backslash, `~` or glob character take a literal fast
path.

**Executor** (`exec.cpp`):
- Status lives in the shell. `break`, `continue` and `return` set
  `sh->flow`.
- `exit`, fatal errors and `set -e` use `__builtin_longjmp` to the
  current subshell's escape point. The handler replays the undo list.
- Redirections push undo records onto a list; they are applied to a
  virtual fd table.
- A builtin writes through `Output`s bound to its fds 1 and 2, flushed
  when it returns.

## Module interfaces

Each module takes an `Arena` and returns its result by value.
Diagnostics come back as text; the core adds bash's
`NAME: line N: ` prefix.
- **arith:** `Arith arith(ArithEnv *, Str expr)` returns
  `{i64 value; Str err; b32 ok;}`. `ArithEnv` supplies get and set
  callbacks for variables, and the recursion depth.
- **pattern:**
  - `b32 patmatch(Str pat, Str s, i32 flags)`. `pat` is in glob form,
    with backslash quoting. Flags: `PM_EXTGLOB PM_NOCASE PM_PATHNAME
    PM_PERIOD PM_DOTGLOB`.
  - `PatSpan patfind(Str pat, Str s, i32 mode, i32 flags)` for `#`,
    `##`, `%`, `%%`, `/`, `//`, `/#` and `/%`.
- **brace:** `Slice<Str> braceexpand(Arena *, Str word)` works on the
  word text, before any other expansion.
- **test:** `i32 testeval(TestEnv *, Str *args, iz n)` returns 0, 1 or
  2, plus a message. `TestEnv` supplies callbacks for stat, access,
  isatty, `-o` options and `-v` variables.
- **printf:** `i32 printfmt(PrintfEnv *, Buf *, Str *args, iz n)`.

## Exit criteria

These are from the plan:
- run-minimal passes on the vos;
- 1e7-iteration loops keep the RSS flat;
- B1, B2, B7, B9 and B10 beat bash.
